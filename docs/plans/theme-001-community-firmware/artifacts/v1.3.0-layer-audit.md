# Deluge v1.3.0 layer audit

## Scope and conclusion

Audited the 32 current layer definitions against the official [v1.3.0 release](https://github.com/SynthstromAudible/DelugeFirmware/releases/tag/v1.3.0), commit [`156500e7c4b756840bd4b116e70a3b27c27d64bb`](https://github.com/SynthstromAudible/DelugeFirmware/commit/156500e7c4b756840bd4b116e70a3b27c27d64bb). The existing base is `9e3132dc17070695b40f69bada5565a33ce428b4`. The release contains 142 commits beyond that base and changes 327 files.

No complete layer is confirmed redundant. Several layers overlap release fixes or existing features, but their full behavior is not established as equivalent. Keep each provisionally; reconcile the partial overlaps when porting. “Keep” means no equivalent was found in the checked release code, not a proof that the behavior cannot exist elsewhere. This is a source and patch audit, not a firmware build or device test.

## Candidate relationship

As checked on 2026-11-11, official `main` is `96c0028037f5945c9dd9ec55c7154c1489ce0681`, 209 commits beyond the current base. The release and `main` have diverged: 59 commits are reachable only from the release and 126 only from `main`. If selecting the release, use `refs/tags/v1.3.0`; the tag commit is not an ancestor of the checked `main` tip.

## Trial replay

An isolated v1.3.0 projection applied the base and layers 0004–0008, then stopped at a reverb conflict in 0009. After provisional, trial-only conflict resolutions, it progressed through 0018 and stopped at the substantially changed waveform renderer in 0019. Conflicts appeared in 0009 (reverb), 0011 (Slicer and test list), 0015 (runtime settings), 0017 (recorder), and 0019 (waveform renderer). These provisional resolutions were made only to inspect later layers; they have not been built, reviewed as a port, or applied to the definitions. Layers 0020–0035 were assessed from their patches and release source, not sequentially replayed.

An initial isolated `main` replay also stopped at 0009, with conflicts in reverb and the audio engine. No base, layer, published branch, firmware installation, or source checkout was changed.

## Recommended next steps

1. Use v1.3.0 as the candidate if a stable, reproducible release is the priority; pin both its tag ref and full commit.
2. Prepare a separate port. Preserve the upstream fixes and reconcile the partial overlaps before carrying the remaining behavior forward.
3. Re-run the full layer stack, refresh the keybinding catalog and source snapshot, run relevant host tests and a firmware build, and review device-facing behavior before considering the result ready.
