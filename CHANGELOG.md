# Changelog

Changes to this fork are listed here. See [DEVIATIONS.md](DEVIATIONS.md) for detailed behavior and compatibility notes.

## Unreleased

The fork is based on [Deluge Community Firmware v1.3.0](https://github.com/SynthstromAudible/DelugeFirmware/releases/tag/v1.3.0).

### Firmware

- Show recognized chords and the latest held note in Keyboard View.
- Add Manual Slicer and Kit workflow improvements, including Kit row copy, paste, and reordering.
- Add a Panic gesture, optional MIDI sustain, externally stepped MIDI Clips, and Kit choke groups.
- Improve waveform displays, Audio Clip editing, Velocity Drums, the Song scale menu, and envelope time controls.

### Repository

- Keep the [keybinding catalog](keybindings/README.md) alongside the layer definitions, with upstream and fork origin tags where source evidence supports them.
- Color the layer dependency graph by firmware area.
